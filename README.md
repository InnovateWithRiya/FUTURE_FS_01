# Personal Professional Portfolio

A clean, responsive, and recruiter-ready portfolio website with dual brightness modes inspired by modern developer portfolios.

## Features
- Professional homepage, projects, about, skills, and contact sections
- Day/Night mode toggle with system preference detection
- Responsive layout for desktop and mobile
- SEO-friendly meta tags
- Animated section reveals

## Tech Stack
- HTML, CSS, JavaScript

## Getting Started
1. Open `index.html` in your browser.
2. Edit the content to use your real details:
   - Name, location, role, and summary
   - Project titles, descriptions, and links
   - Email, LinkedIn, and GitHub

## Customization Notes
- Update hero/profile images by replacing the image URLs in `index.html`.
- Adjust colors and gradients in `styles.css` under `:root`.
- To enable automated email notifications, connect the contact form to a backend or form provider (e.g., Express + Nodemailer, Formspree, or Getform).

## Deployment
- GitHub Pages: Push the repo and enable Pages in repository settings.
- Netlify/Vercel: Drag-and-drop the project folder or connect the repo for continuous deploys.
